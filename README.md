# Project2

This project involves the development of a Python-based automation tool for the Nebraska Department of Transportation (NDOT). Our firm has been tasked with migrating NDOT’s legacy concrete mix design model from a spreadsheet-based environment (Microsoft Excel) to a robust, programmatic environment using Python. The goal is to modernize the calculation workflow, ensuring that concrete mix designs are consistent, repeatable, and ready for future web-based integration.
